# Customer Shopping Behavior Analysis

End-to-end data analytics project that turns 3,900 raw retail transactions into actionable business
recommendations — covering data cleaning, database modeling, SQL analysis, and an interactive
Power BI dashboard.

**Tech stack:** Python (pandas) · MySQL · SQL · Power BI

---

## 📌 Project Overview

A retail company wants to understand its customers' shopping behavior in order to improve sales,
customer satisfaction, and long-term loyalty. This project analyzes a transactional dataset to answer:

> *How can the company use consumer shopping data to identify trends, improve customer engagement,
> and optimize marketing and product strategy?*

The workflow mirrors what a data analyst does on the job:

1. **Data Preparation (Python)** — clean, standardize, and engineer features from the raw dataset.
2. **Database Modeling (MySQL)** — load the cleaned data into a relational database.
3. **Data Analysis (SQL)** — write business-focused queries to answer 10 key questions about
   customer segments, loyalty, and purchase drivers.
4. **Visualization (Power BI)** — build an interactive dashboard summarizing the findings.
5. **Reporting** — translate the analysis into concrete business recommendations.

## 🗂️ Dataset

- **3,900 rows / 18 columns** of retail transaction data
- Customer demographics: age, gender, location, subscription status
- Purchase details: item, category, amount, season, size, color
- Behavioral signals: discount usage, review rating, previous purchases, shipping type, purchase frequency

## 🔧 Data Preparation (Python)

Performed in [`Customer_Shopping_Behavior_Analysis.ipynb`](./Customer_Shopping_Behavior_Analysis.ipynb):

- Loaded and explored the dataset with `pandas` (`.info()`, `.describe()`)
- Identified and imputed 37 missing `review_rating` values using the **median rating per product category**
- Standardized column names to snake_case for consistency
- Engineered new features:
  - `age_group` — binned customer age into quartiles (Young Adult / Adult / Middle-aged / Senior)
  - `purchase_frequency_days` — converted categorical purchase frequency into a numeric day count
- Checked `discount_applied` vs. `promo_code_used` for redundancy and dropped the duplicate column
- Loaded the cleaned dataset into **MySQL** using `SQLAlchemy` + `PyMySQL`

## 🗄️ Database: MySQL

The cleaned data is loaded into a MySQL database (`customer_behavior`) and queried directly with SQL.
Credentials are read from environment variables rather than hardcoded, so the notebook is safe to share
and reuse. See [Setup](#-setup--how-to-run) below.

## 📊 SQL Analysis

Ten business questions answered in [`customer_behavior_sql_queries.sql`](./customer_behavior_sql_queries.sql), including:

| # | Business Question |
|---|--------------------|
| 1 | Total revenue generated by male vs. female customers |
| 2 | Customers who used a discount but still spent above the average |
| 3 | Top 5 products by average review rating |
| 4 | Standard vs. Express shipping — average spend comparison |
| 5 | Subscribers vs. non-subscribers — average spend & total revenue |
| 6 | Top 5 products by discount-usage rate |
| 7 | Customer segmentation — New / Returning / Loyal |
| 8 | Top 3 best-selling products per category |
| 9 | Are repeat buyers (5+ purchases) more likely to subscribe? |
| 10 | Revenue contribution by age group |

Queries use CTEs, window functions (`ROW_NUMBER() OVER PARTITION BY`), conditional aggregation,
and subqueries — written and tested against **MySQL 8.0**.

## 📈 Power BI Dashboard

An interactive dashboard ([`customer_behavior_dashboard.pbix`](./customer_behavior_dashboard.pbix))
connects to the MySQL database to visualize:

- Revenue breakdown by gender, age group, and subscription status
- Top-performing products and categories
- Discount usage patterns and their impact on spend
- Customer segment distribution (New / Returning / Loyal)

## 💡 Key Business Recommendations

- **Boost subscriptions** — promote exclusive benefits to convert non-subscribers, who show measurably different spending patterns.
- **Loyalty programs** — reward repeat buyers to move them from "Returning" into "Loyal" segments.
- **Review discount policy** — several top-selling products lean heavily on discounts; balance sales volume against margin.
- **Product positioning** — spotlight top-rated and best-selling items per category in marketing campaigns.
- **Targeted marketing** — prioritize high-revenue age groups and express-shipping customers, who represent higher-value segments.

## 🛠️ Setup & How to Run

### Prerequisites
- Python 3.9+
- MySQL Server 8.0+ (running locally or remotely)
- Power BI Desktop (optional, to open the dashboard)

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd customer-shopping-behavior-analysis
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Create the MySQL database
```sql
CREATE DATABASE customer_behavior;
```

### 4. Configure credentials
Copy `.env.example` to `.env` and fill in your MySQL credentials:
```bash
cp .env.example .env
```

### 5. Run the notebook
Open `Customer_Shopping_Behavior_Analysis.ipynb` and run all cells. This will:
- Clean and transform the raw CSV
- Load the cleaned data into your MySQL `customer_behavior` database

### 6. Run the SQL analysis
Open `customer_behavior_sql_queries.sql` in MySQL Workbench (or your client of choice) and run the queries against the `customer` table.

### 7. Explore the dashboard
Open `customer_behavior_dashboard.pbix` in Power BI Desktop and point the data source at your MySQL database.
